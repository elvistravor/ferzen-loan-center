FERZEN LOAN SERVICES — UPDATED PROJECT

This package includes client registration consent, a touch signature pad, server-side consent validation, registration attribution, and owner filters/sorting for the client register.

To run:
1. Install Node.js 20 or newer.
2. Copy .env.example to .env and set a long random SESSION_SECRET and a strong SETUP_KEY.
3. Run npm install.
4. Run npm start.
5. Open http://localhost:3000 and complete owner setup.

For online deployment, follow DEPLOY-ON-PHONE.md and README.md. Configure persistent storage for both the SQLite database and uploaded files. Do not use real customer ID photos, NINs, or signatures until deployment security, backups, privacy notices, and legal requirements have been reviewed.
